# IluCanvas — notes for agents working on this repo

An infinite reference board (PureRef / FigJam-like) as a static web app: vanilla
ES modules, no build step, no dependencies. Every board is one `.ilucanvas`
file (a ZIP). Sister project: `E:\Git\IluBoard` (kanban) — the visual styles
(Fun / Calm / Oli tokens in `src/app/styles.css`) and the CLI/bundle approach
come from there; keep them consistent.

## Map

- `src/core/` — no DOM, runs in Node and the browser; the CLI bundles it.
  - `zip.js` reader (random access over a `{ size, read(offset, len) }` reader) / writer (`ZipWriter`, chunks), ZIP64, UTF-8 names, recovery scan.
  - `canvasfile.js` — the `.ilucanvas` layout and save planning (`tail` / `append` / `full` modes).
  - `model.js` — canvas.json: normalize, validate, serialize, geometry, groups (nested via `parent`), arrange, merge3.
  - `ops.js` — the batch op vocabulary shared by the CLI (`apply`) and `window.ilucanvas.apply`.
  - `imageinfo.js` (type / size from headers), `crc32.js`, `pureref.js` (PureRef 1.x/2.x reader, see docs/PUREREF.md).
  - `markdown.js` note text (Markdown subset ↔ blocks); `connectors.js` connector routes (elbow routing avoids the end items); `ink.js` stroke frames, hit tests, `reframe`; `describe.js` the one-line-per-item text of `ls` / `ilucanvas.list()`; `video.js` YouTube links, times, timecodes; `purdoc.js` a parsed PureRef board → our items (images, groups, notes, drawings); `table.js` tables as data: rows / columns in and out, cells, TSV / CSV, Markdown marks over cells, the height estimate.
- `src/app/` — the UI.
  - `main.js` shell: state, history (undo = snapshots of the immutable `items` array + `assets` object), boards bar, top bar, save / autosave, outside-change polling + merge, adding images, menus, keyboard, settings, links, `window.ilucanvas`, `?demo=N`.
  - `board.js` renderer + input (canvas 2D: scene + overlay; culling; LOD via `images.js`).
  - `images.js` decoded-bitmap cache (levels 128/512/2048/8192 — 4096 on iOS; memory budget, 400 MB on iOS) + worker pool; `worker.js` hashes / previews new images.
  - `store.js` the open document and its bytes; `disk.js` sources (File System Access, dev server, memory, `local` = boards kept in OPFS for Safari / Firefox) + IndexedDB; `opfs.js` + `opfsworker.js` OPFS writes (createWritable, or a sync access handle in a worker — Safari); `remote.js` shared links (Google Drive API v3, OPFS cache); `colorpicker.js` the custom colour picker; `videoplayer.js` the YouTube player over a video card (IFrame API) and its study bar.
  - `background.js` six background patterns; `minimap.js`; `ui.js` (h(), dialogs, menus, toasts); `i18n.js` (RU / EN — add every new string to both).
  - `text.js` note / shape text layout and drawing; `editor.js` the contentEditable note editor; `notes.js` creating notes / shapes / connectors / tables, editing table cells, and the floating selection bars; `table.js` table layout (a cell is laid out and edited as a small `type: "cell"` note), drawing, the cell under a point; `shapes.js` shape and connector drawing; `ink.js` stroke outlines (vendored perfect-freehand in `vendor/`).
- `tools/ilucanvas.mjs` CLI source → `ilucanvas.mjs` (generated by `tools/bundle.mjs`; commit both). `tools/serve.mjs` dev server. `tools/icons.mjs` writes the PNG icons (home screen, install) from the logo's geometry.

## Rules

- Items are immutable: replace objects (`patchItems`, spread), never mutate in place; `doc.assets` is copy-on-write too. Undo relies on it.
- Every edit in the app goes through `edit(label, fn)` or the board's `cb.commit` so it is undoable and autosaved.
- New canvas.json fields: add them to `ITEM_KEYS`/`ASSET_KEYS` order in model.js, FORMAT.md, the schema, and keep unknown fields round-tripping.
- Never load whole image files into memory when a Blob slice will do (`entryBlob`).
- Keep `src/core` free of DOM and Node APIs (the bundler fails on dynamic import / import.meta there).

## Run / test

```bash
npm test                         # node --test "test/*.test.js"
node tools/bundle.mjs            # regenerate ilucanvas.mjs (CI checks it is up to date)
node tools/serve.mjs examples --port 8790   # http://localhost:8790/?file=test.ilucanvas  · ?demo=30 · ?demo=1500
```

In the app: `ilucanvas.perf({ draw: true })` draws a frame synchronously and reports its time (works in a hidden tab).

Safari / iPad cannot be run here: `?nofsa` makes Chrome behave as without File System Access (boards in OPFS), `?opfs=sync` writes OPFS the way Safari does (worker + sync access handle). Touch / pencil input: fingers pan in the drawing tools once a pencil was seen, long press = context menu, two taps = double click; Safari trackpad pinch comes as gesture* events.
